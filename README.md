# dead-x

DEAD X — Lobby prototype and project scaffold.

This repository will contain the prototype and project files for DEAD X, a zombie battle royale. Start by opening the lobby prototype in a browser:

- Open `lobby/index.html` in your browser to see the first visual mockup of the lobby UI (HTML/CSS prototype inspired by the provided reference image).

Files added in this change:
- `lobby/index.html` — interactive HTML prototype of the lobby UI.
- `lobby/styles.css` — styles for the prototype.
- `docs/LOBBY_DESIGN.md` — notes and implementation plan for turning the prototype into a Unity UI.
